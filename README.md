# 自动化报告生成工具

这是一个用于自动化生成PPT报告的工具，可以将视频文件和截图自动插入到PPT模板中的指定位置。

## 功能特性

- **图形化界面**: 提供友好的GUI操作界面
- **批量处理**: 支持批量生成报告
- **视频处理**: 自动提取视频最后一帧作为截图
- **智能匹配**: 文件名即索引，无需配置映射表
- **智能尺寸**: 支持容器自适应（Auto-Fit）和指令控制（Smart Sizing）
- **锚点定位**: 使用锚点形状精确定位，支持大小写不敏感
- **对比报告**: 支持生成对比报告

## 使用方法

### 1. 图形界面方式（推荐）

运行主程序：
```bash
python gui_main.py
```

界面操作步骤：
1. 选择执行脚本（普通生成或对比生成）
2. 选择PPT模板文件
3. 设置视频文件目录
4. 点击"开始生成"按钮

### 2. 命令行方式

普通报告生成：
```bash
python generate_report.py --template 自动化模板.pptx --video_dir 视频
```

对比报告生成：
```bash
python generate_compare_report.py --template 自动化模板.pptx --video_dir 视频
```

## 视频文件映射规则
**(v2.0 新增：约定优于配置)**

系统不再依赖配置文件，而是直接扫描 PPT 中的锚点标签。

**规则**：
1. **PPT 标签**: `VID_wendu`
2. **视频文件**: 在视频文件夹中查找 `wendu.mp4` (或 avi/mov 等)
3. **自动匹配**:
   - **精确匹配 (优先)**: 文件名 `wendu.mp4` 完全匹配标签 `wendu`。
   - **模糊匹配 (备选)**: 如果找不到精确文件，程序会尝试寻找最相似的文件名（相似度 > 60%）。
     - 例如：标签 `wendu` 可以匹配到 `wengdu.mp4` 或 `wendu123.mp4`。
     - 例如：标签 `qipao` 可以匹配到 `qapao.mp4`。

## 锚点命名规则

在 PPT 模板中使用文本框或矩形，并在**形状内输入文本**或**修改形状名称**：

### 1. 基础命名 (大小写不敏感)
- **视频**: `VID_<key>` (例如: `VID_wendu`, `vid_wendu`)
- **图片**: `IMG_<key>` (例如: `IMG_result`)

### 2. 智能尺寸控制
系统支持两种模式，并可通过后缀指令强制控制：

- **容器模式 (Auto-Fit)**: 
  - 手动将文本框拉大（宽/高 > 50磅），视频将**保持比例居中填充**在该区域内。
- **锚点模式 (Auto-Expand)**:
  - 默认小文本框，视频将以该点为中心，按默认尺寸（Slide宽度的80%）向四周展开。
- **强制指令**:
  - `_W[数值]`: 锁定宽度 (例如 `VID_wendu_W600`)
  - `_H[数值]`: 锁定高度 (例如 `VID_wendu_H400`)
  - `_S[数值]`: 按原始分辨率缩放 (例如 `VID_wendu_S1.0` 表示原图尺寸)

## OCR 曲线数据提取 (v2.3 新增)

系统支持自动识别图表截图中的曲线，提取其终点数值并填入 PPT。

### 1. 占位符格式
在 PPT 文本框中输入以下格式的占位符：

- **基础格式**: `{{CURVE:Key}}`
  - 含义：自动寻找与 `Key` 相关的图表（通常是名为 `VID_Key` 或 `IMG_Key` 插入的图片），分析其曲线终值。
  - 示例：`当前温度: {{CURVE:wendu}} ℃` -> `当前温度: 25.42 ℃`

- **格式化输出**: `{{CURVE:Key|.1f}}`
  - 含义：指定保留小数位数。
  - 示例：`{{CURVE:wendu|.1f}}` -> `25.4`

### 2. 工作原理
1. **自动截图**: 程序先将所有视频/图片插入 PPT。
2. **页面分析**: 针对包含 `CURVE` 标签的页面，程序会自动对该页进行截图。
3. **智能识别**: 
   - 自动定位页面中的图表区域（支持过滤背景干扰）。
   - 使用 OCR 识别左侧 Y 轴刻度，建立坐标系。
   - 追踪曲线轨迹，计算最右侧终点的物理数值。

### 3. 环境要求
- 必须安装 **Tesseract-OCR** 并将程序文件放入项目根目录的 `Tesseract-OCR/` 文件夹中。
- 文件夹结构：
  ```
  自动化方案/
  ├── Tesseract-OCR/
  │   ├── tesseract.exe
  │   ├── tessdata/
  │       └── eng.traineddata
  ```

## 追加对比模式 (Append Mode)
**(v2.1 新增：对象溯源)**

此模式用于在“已有 PPT”的视频旁边插入新视频进行对比。

**原理**：
1. **生成时埋点**：v2.0+ 生成的 PPT，所有视频对象会自动命名为 `SmartTag_<Key>`（例如 `SmartTag_wendu`）。
2. **追加时识别**：程序扫描 PPT 中隐藏的 `SmartTag_` 名称，精准定位旧视频位置。
3. **自动排版**：旧视频自动左移，新视频插入右侧。

**注意**：
- 仅支持由本工具 v2.0+ 生成的 PPT。
- 如果是旧版 PPT，需手动在“选择窗格”中将视频形状重命名为 `SmartTag_<key>` 才能被识别。

## 注意事项

1. 确保视频文件存在于指定的视频目录中
2. PPT模板需要预先设置好锚点形状
3. 如果某个视频文件不存在，对应的PPT页面将保持空白
4. 生成的报告将保存在与脚本相同的目录下
5. 建议使用英文路径，避免中文路径可能导致的兼容性问题

## 故障排除

### 常见问题

1. **PowerPoint无法启动**
   - 确保已安装Microsoft PowerPoint
   - 检查是否有其他PowerPoint实例正在运行

2. **视频文件无法读取**
   - 检查视频文件路径是否正确
   - 确保视频文件格式受支持（推荐mp4格式）
   - 检查视频文件是否损坏

3. **锚点形状找不到**
   - 确认PPT模板中的形状命名是否正确
   - 检查形状是否位于正确的幻灯片上
