# 自动化报告工具智能化改造实施方案

根据您的需求，我们将废弃 `config.json` 中的 `video_mapping` 配置，转为“约定优于配置”的模式。这意味着程序将直接扫描 PPT 中的 `VID_` 标签，并在视频文件夹中查找同名文件。

## 核心改造模块

### 1. `ppt_automation.py` (核心逻辑增强)
我们将重构 `scan_placeholders` 和插入逻辑，使其更智能。

*   **全量动态扫描**:
    *   不再依赖传入的 `valid_keys` 列表。
    *   遍历所有 Slide 的所有 Shape。
    *   **优先检查文本内容**: 读取 Shape 的 `TextFrame.TextRange.Text`。如果以 `VID_` 或 `IMG_` 开头，提取 Key 和指令 (如 `VID_wendu_W600`)。
    *   **备选检查 Shape 名称**: 如果文本为空，检查 `Shape.Name` (兼容旧模式或纯形状标注)。
    *   返回包含 `key`, `directives` (宽/高/比例设置), `is_container` (是否作为容器) 的完整动作列表。
*   **智能尺寸自适应 (Smart Sizing)**:
    *   **容器模式 (Container Mode)**: 如果检测到占位符被用户手动拉大 (例如宽/高 > 50)，则将视频/图片**保持比例居中填充**在该矩形区域内。
    *   **锚点模式 (Anchor Mode)**: 如果占位符很小 (默认文本框)，则以该形状的中心为基准，按默认尺寸 (如 Slide 宽度的 80%) **向四周展开**插入。
    *   **指令解析**: 支持 `_W[宽]`, `_H[高]`, `_S[缩放]` 等后缀指令的解析和应用。

### 2. `utils.py` (工具函数增强)
*   新增 `find_media_file(directory, key)` 函数：
    *   在指定目录下搜索文件名匹配 `key` 的文件。
    *   支持多种后缀 (mp4, avi, mov, png, jpg 等)。
    *   实现“模糊匹配”或“精确匹配”策略 (优先精确匹配)。

### 3. `generate_report.py` (主程序重构)
*   **移除配置依赖**: 删除读取 `video_mapping` 的代码。
*   **流程重组**:
    1.  初始化 PPT。
    2.  调用 `ppt.scan_placeholders()` 获取所有待处理项。
    3.  遍历待处理项，使用 `utils.find_media_file` 在视频目录中查找对应文件。
    4.  如果找到文件：
        *   若是视频且标签为 `VID_` -> 直接插入。
        *   若是视频但标签为 `IMG_` -> 调用 `extract_last_frame` 提取最后一帧图片 -> 插入图片。
        *   若是图片 -> 直接插入。
    5.  清理占位符 (删除 `VID_` 文本)。
    6.  保存报告。

### 4. `generate_compare_report.py` (对比报告重构)
*   同样移除 `video_mapping`。
*   扫描 PPT 获取 Key。
*   分别在 `video_dir_a` 和 `video_dir_b` 中查找文件并进行左右对比插入。

### 5. `generate_append_report.py` (追加报告调整)
*   **注意**: 由于追加模式通常是在“已有 PPT”上操作，如果已有 PPT 中的 `VID_` 标签已被之前生成的视频覆盖或删除，此模式将无法通过标签定位。
*   **调整策略**: 假设该工具主要用于“基于带标签的模板”生成报告。我们将把此脚本也更新为“扫描模式”，即要求输入的 `existing_ppt` 必须包含 `VID_` 标签才能工作。

### 6. `config.json` (清理)
*   删除 `video_mapping` 字段，仅保留全局样式配置 (如 `labels`)。
